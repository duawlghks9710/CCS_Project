# 통합 DSS 대시보드

A/B/C/D 4개 서브시스템이 Supabase에 적재한 데이터를 조회하여 MCDA(다기준의사결정)
매트릭스로 통합하고, 정화공법 시나리오별 비교 대시보드를 제공한다.

## 구성
- `schema.sql` : 전체 통합 DB 스키마 (Supabase에 적용됨)
- `mcda_weights.md` : 평가 기준별 가중치 정의 (리스크 저감 / 비용 / 에너지 자립률 등)
- `app/` : 대시보드 애플리케이션 (3주차 개발 예정)
