# 프로젝트 헌장 (Project Charter)

## 과제명
기후변화 대응형 제로에너지 자율 모니터링·정화 통합 DSS
(CCS자연기반해법(NbS) 계획및설계 — 착수 트랙 ① 브라운필드 DSS 기반)

## 대상지 (후보)
부평 캠프마켓(또는 구 장항제련소/용산공원 등 유사 브라운필드) — 추후 1주차 중 확정

## 문제정의
오염 부지의 복원·관리 의사결정을 "센싱 → 리스크 평가 → 정화설계 → 에너지 자립"
단일 파이프라인으로 자동화·정량화하여, 기후변화로 인한 오염물질 독성 변화까지
반영한 의사결정지원시스템(DSS)을 구축한다.

## 참여 전공 및 역할

| 전공 | 서브시스템 | 핵심 기술 |
|---|---|---|
| 전자정보시스템공학 | A. 센싱 | 저전력 임베디드 센서, edge 이상탐지 |
| 생명과학(분자독성학) | B. 리스크 평가 | 온도의존 QSAR 독성 모델링 |
| 그린화학공학 | C. 정화 | 이온교환수지 합성·흡착 최적화 |
| 에너지그리드학 | D. 에너지 자립 | 제로에너지 설계, PV/ESS sizing |

## 유의사항
- LLM 활용은 추출·코딩·설명 보조로 한정한다 (원자료 조작·창작 금지)
- 정보공개청구·착수 주 실사자료는 `data/raw/`에 보관하되 git에는 추적하지 않는다 (용량/보안)
- 서브시스템 간 인터페이스(입출력 데이터 포맷)는 1주차 내 `01_architecture.md`에 확정한다
